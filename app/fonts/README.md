# Fonts

Atkinson Hyperlegible, Regular and Bold (woff2), by the Braille Institute of America, licensed under the SIL Open Font License 1.1 (`OFL.txt`).

- **Source:** https://github.com/googlefonts/atkinson-hyperlegible (`fonts/webfonts/`, `main` branch).
- **Downloaded:** 14 Nov 2026, with the user's approval.
- **Files:** each about 23 kB; both checked as woff2 (`wOF2` header).
- **Why this face:** it was designed to tell confusable characters apart (l/1/I, O/0). That is UI_RESEARCH R4 (NASA-STD-3001 App. F.5.1.2–3). It is self-hosted, so the interface stays fully offline (N1).
